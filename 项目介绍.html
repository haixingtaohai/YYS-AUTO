核心模块

三大核心模块各司其职，构成完整的自动化引擎

■ main.py -- 主程序入口
~1600 行
应用程序的核心枢纽，包含所有 GUI 逻辑和自动化调度。基于 tkinter 构建，采用选项卡架构实现多设备并行管理。
AutoClickerUI DeviceTab SettingsTab Menu 菜单栏 快捷键绑定 多线程 JSON 配置
■ image_recognizer.py
~243 行
OpenCV 模板匹配引擎。使用 TM_CCOEFF_NORMED 归一化交叉相关算法，配合 ADB 截图和点击模拟，实现高精度游戏界面识别。内置详细日志记录，将每次识别结果（图片名称、中心坐标、置信度）写入 logs 目录。
ImageRecognizer matchTemplate 模板缓存 阈值 0.90 日志记录
■ adb.py
~108 行
ADB 设备管理层与日志基础设施。负责模拟器通信、自动发现 platform-tools 目录、验证设备分辨率（强制 1280x720）。V2.6 引入 _FilterDisabled 过滤器类 + set_logging_enabled() 全局开关，日志默认关闭，用户可在菜单栏中启用。
ADBManager 设备发现 分辨率验证 logging

快速开始

按照以下步骤快速部署和运行 YYS-AUTO

1
安装 Android 模拟器
安装 MuMu、雷电或其他支持 ADB 的 Android 模拟器。在模拟器设置中将分辨率调整为 1280x720（横屏），并开启 ADB 调试。
2
安装 Python 依赖
确保已安装 Python 3.8 或更高版本，然后运行 install.bat 或手动执行 pip install opencv-python。
3
连接 ADB 设备
在模拟器中查看 ADB 端口（通常为 5555），在 YYS-AUTO 中输入对应的 IP 和端口连接设备。程序会自动检测设备分辨率是否符合要求。
4
选择场景并启动
在选项卡中选择需要的游戏场景预设（如业原火、魂土等），设置挑战次数和其他参数，点击启动即可开始自动化运行。
5
等待完成
程序会在后台自动运行。任务完成后播放音效通知。可随时通过界面停止或调整参数。所有设置自动保存，下次启动无需重新配置。
