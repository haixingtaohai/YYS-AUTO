# YYS-AUTO v2.10

阴阳师手游自动化辅助工具，基于 ADB + OpenCV 图像识别，自动完成游戏中的各类重复性任务。

> 适用于安卓模拟器 / 局域网设备，支持多设备同时运行、队员司机联动、绘卷模式等多种高级功能。

## 功能特性

- **图像识别驱动** — 基于 OpenCV 模板匹配，无需 root，兼容所有安卓设备
- **多设备并行** — 多标签页设计，一台电脑同时控制多台设备运行不同场景
- **队员司机联动** — 司机号自动邀请、等待队员准备后发起挑战
- **绘卷模式** — 结界突破与困28之间自动切换，最大化刷券效率
- **斗技段位停止** — 晋升时自动暂停，避免误操作
- **顶号自动重登** — 被踢下线后自动关闭游戏、重启、重新进入
- **自动关闭加成** — 挑战达到设定次数后自动关闭御魂加成，节省资源
- **系统通知** — Windows Toast 通知 + 自定义 WAV 提示音
- **Numba 加速** — 可选 JIT 加速，大幅降低截图处理耗时
- **详细日志** — 运行日志按时间戳分类存储，方便复盘

## 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/yourname/yys-auto.git
cd yys-auto
```

### 2. 安装依赖

双击运行 `bat/install.bat`，或手动执行：

```bash
pip install opencv-python numpy winotify
```

可选加速组件（非必需）：

```bash
pip install numba PyTurboJPEG
```

### 3. 连接设备

- **本地模拟器**：确保模拟器已开启 ADB 调试，程序默认连接 `127.0.0.1:16384`
- **局域网设备**：在设置中修改 IP 和端口

### 4. 启动程序

双击 `bat/run.bat`，或：

```bash
python main.py
```

### 5. 选择场景 → 开始

1. 在「设备」标签页中选择已连接的设备
2. 下拉选择要运行的场景
3. 设置挑战次数（0 表示无限循环）
4. 点击「开始」

> 详细使用教程请参阅 `使用文档第一次使用必看/` 目录下的文档。

## 配置说明

`config.json` 主要配置项：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `adb_ip` | string | `127.0.0.1` | ADB 连接 IP |
| `adb_port` | string | `16384` | ADB 端口（UU远程: `16416`） |
| `link_enabled` | bool | false | 队员司机联动开关 |
| `close_jiacheng_enabled` | bool | false | 是否自动关闭御魂加成 |
| `close_jiacheng_wait` | int | 30 | 关闭加成等待秒数 |
| `dinghao_wait` | int | 30 | 顶号后等待重登秒数 |
| `huijuan_mode` | bool | false | 绘卷模式开关 |
| `dj_jinsheng_stop` | bool | false | 斗技晋升自动停止 |
| `sound_enabled` | bool | false | 提示音开关 |
| `notify_enabled` | bool | false | 系统通知开关 |
| `logging_enabled` | bool | false | 日志记录开关 |
| `tabs` | object | - | 各设备标签的独立配置 |

## 场景详解

### 组队联动（司机+队员）

1. 在两台设备上分别选择「司机」和「队员」
2. 勾选「队员司机联动」
3. 司机号点击「开始」后，等待所有队员准备完毕才发起挑战

### 绘卷模式

1. 勾选「绘卷模式」
2. 选择「结界突破」或「困28单人/队长」
3. 程序会在两种场景间自动切换：
   - 结界突破有券 → 刷结界
   - 结界突破0券 → 切困28
   - 困28攒够30券 → 切回结界

### 斗技段位停止

- 勾选「段位晋升时停止」后，斗技达到晋级赛时会自动暂停
- 取消勾选则自动跳过晋级战继续匹配

### 加速优化

安装 `numba` 和 `PyTurboJPEG` 后，程序自动启用：
- BGR→Gray 转换的 JIT 加速
- JPEG 截图的 Turbo 解码
- Raw RGBA 截图直读模式（绕过 PNG 编解码）

## 常见问题

**Q: 图像识别不准确，经常点错？**

A: 确保模拟器分辨率为 720×1280（或等比例），DPI 设置一致。模板基于此分辨率制作。

**Q: 提示"未检测到设备"？**

A: 检查 ADB 连接状态，确保 IP 和端口正确。可在命令行运行 `platform-tools\adb.exe devices` 验证。

**Q: 多开时某个设备卡住？**

A: 检查 CPU/内存占用，多开建议关闭加速模块中的 TurboJPEG，使用纯 OpenCV 模式。

**Q: 如何制作自定义模板？**

A: 截取游戏画面中需要识别的区域，裁剪保存为 PNG 放入对应场景的 `png/` 子目录。模板建议尺寸与游戏分辨率一致。
